# ミッション・報酬UI QA

更新日: 2026-08-15  
対象: PR #9 ミッション・報酬状態UI

## 1. 受入条件

- クエスト画面内で「今日のメニュー」と「ミッション・報酬」を切り替えられる
- 初期表示は従来どおり「今日のメニュー」とする
- デイリー3件、ウィークリー2件を `data/quests/core.json` から表示する
- 各カードにタイトル、説明、現在値、目標値、進捗率、報酬XP、状態を表示する
- 状態は「進行中」「達成済み」「受取済み」の3種を区別する
- 達成済みの記録はセット取消や当日リセット後も達成済みとして表示する
- 未付与報酬を受取済みと誤表示せず、「報酬予定」または「付与待ち」と明示する
- クエスト定義を取得できない場合もセット記録、XP、能力値の更新を継続できる

## 2. 操作・アクセシビリティ

- 切替ボタンは `role="tab"`、パネルは `role="tabpanel"` で関連付ける
- 選択中の切替ボタンに `aria-selected="true"` を設定する
- 左右矢印キーで2つのタブを切り替え、フォーカスも移動する
- 切替ボタンの高さを44px以上とし、隣接する誤タップを避ける間隔を持たせる
- 状態を色だけに依存せず、カード内の日本語ラベルでも伝える
- `prefers-reduced-motion` 設定時は進捗バーの遷移を最小化する

## 3. レスポンシブ確認

確認幅: 320px / 350px / 390px / 430px

- タブ文言が横方向にはみ出さない
- ミッション名と説明が報酬表示へ重ならない
- 進捗値と報酬XPが同一行で判読できる
- 下部ナビゲーションに最終カードや注意書きが隠れない
- 横スクロールが発生しない

## 4. 回帰確認

- 種目フィルター、セット完了／取消、当日リセットが従来どおり動作する
- トレーニング実行画面から戻るとクエスト画面へ復帰する
- セット完了1回あたりの通常XPは +10 のまま変わらない
- `muscleMasterStateV2` と旧V1データ移行を維持する
- PWAキャッシュ更新後に `quest-core.js` とクエストJSONをオフライン利用できる
