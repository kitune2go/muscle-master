# Muscle Master — MASTER_SPEC 更新差分

更新日: 2026-08-15  
対象: `00_MASTER_SPEC_Muscle_Master v1.1` の §23.6「現在地」と §23.7「次の推奨作業」

この文書は、現行MASTER_SPECの機能要件を変更せず、GitHub実装の到達点と優先順位を更新するための差分です。内容が競合する場合は、本差分の記載を優先します。

## 1. 現在地

| フェーズ | 状態 | GitHub実装 |
|---|---|---|
| Phase 0: Foundation | 完了 | PWA、`localStorage`、曜日別メニュー、XP・レベル、テスト |
| Phase 1: Visual Design | 完了 | UIコンセプトシート準拠のGolden Screen、390px基準のレスポンシブUI |
| Phase 2: Character System | 基本完了 | トレーナー切替基盤、ユーザー名・トレーナー名編集、既存素材の差替え構造 |
| Phase 3: Training UX | 選択画面まで完了 | 曜日メニュー、カテゴリ絞り込み、回数・時間、XP、セット状況 |
| Phase 4: Records | 基本完了 | 直近履歴、累計セット、継続日数 |

## 2. 今回統合する範囲

- 「クエスト」画面を「トレーニング選択」画面として再構成
- 今日の曜日メニューと全体セット進捗を上部に固定表示
- `すべて / 筋力 / 体幹 / 柔軟 / 持久力` の5カテゴリ絞り込み
- 種目カードに対象部位、回数または時間、獲得可能XP、セット完了数を表示
- 既存のセット完了・取消、XP、ステータス成長、レベルアップ、保存データを継続利用
- 該当種目がないカテゴリの空状態を明示
- キャラクター画像を選択画面に重ねず、種目名・ユーザー名・操作領域を常時読める状態にする

## 3. 互換性の固定条件

- 保存キー `muscleMasterStateV2` を維持する
- 旧 `muscleMasterStateV1` からの移行を維持する
- セット完了1回あたり `+10 XP` を維持する
- ユーザー名・トレーナー名の編集と表示を維持する
- トレーナー切替基盤と既存キャラクター素材の参照先を変更しない
- 320〜430px幅で横方向のUI欠けを発生させない

## 4. 次の推奨作業

次はMASTER_SPEC §10.3に沿った「トレーニング実行画面」を独立したPRで実装します。

1. 選択した種目名と回数・時間の固定表示
2. セット進行と一時停止
3. 時間種目用タイマー
4. フォームアドバイス
5. 完了後のXP・能力値フィードバック

キャラクター画像の最終差替えは、UIフローと表示領域が安定した後に行います。

## 5. クエスト拡張方針

今後は「トレーニング」と「クエスト」を次のように分離します。

- **トレーニング**：種目選択、セット実行、回数・時間、タイマー、完了記録
- **クエスト**：記録された行動の条件判定、進捗、達成、報酬、演出

クエスト画面は、将来的に `今日のメニュー` と `ミッション・報酬` の2領域を持つ構成とします。デイリー、ウィークリー、チャレンジ、イベント、隠し実績を同一の定義形式で追加できるデータ駆動方式を採用します。

実装順序は次のとおりです。

1. トレーニング実行画面・タイマー
2. クエスト定義と進捗判定の共通基盤
3. ミッション・報酬UI
4. キャラクター反応、スタンプ、紙吹雪、宝箱、称号等の演出キュー

詳細設計は `docs/QUEST_ARCHITECTURE.md` を参照してください。
