# トレーニング実行画面 QA

対象画面: `#workout`  
基準幅: 390px  
対応幅: 320〜430px

## 遷移

- トレーニング選択カードの「開始」から対応する種目を開ける
- 戻る操作で選択中のカテゴリとセット記録を維持したまま一覧へ戻る
- 実行する種目を切り替えると、タイマーが停止・初期化される
- 再読み込みで実行画面を直接復元せず、安全に選択画面へ戻る

## 表示

- 種目名、対象部位、回数・時間、現在セット、フォーム説明が読める
- トレーナー画像、トレーナー名、種目情報、タイマーが互いに重ならない
- トレーナー名が20文字でも画像の下で折り返され、操作領域を覆わない
- 完了、現在、未完了のセット状態を色以外の数字・チェックでも判別できる
- 320px、390px、430pxで画面全体の横スクロールが発生しない

## 回数種目

- 目標回数を表示する
- 開始後は経過時間を計測する
- 一時停止、再開、リセットが機能する
- 経過時間にかかわらず、ユーザー判断でセットを完了できる

## 時間種目

- プランク等で設定時間からカウントダウンする
- 0秒で自動停止し、タイマー完了を文字と効果音で通知する
- 一時停止、再開、リセットが機能する
- タイマー終了前でも体調に応じて中止またはセット完了を選べる

## 記録

- セット完了で既存仕様どおり `+10 XP`、能力値、累計セットが更新される
- 完了後は次の未完了セットへ進む
- 全セット完了後は完了表示とメニューへ戻るボタンが出る
- 実行画面からセット完了しても `muscleMasterStateV2` の既存データ構造を維持する
- レベルアップ条件に到達した場合は既存のレベルアップ演出が動作する

## アクセシビリティ・安全

- 操作ボタンに読み上げ可能な名称がある
- 状態変化を `aria-live` で通知する
- `prefers-reduced-motion` で不要な動きを抑制する
- 痛み、しびれ、めまいがある場合の中止案内を常時確認できる
