# Developer QA Reset

## 目的

本番ユーザー向けの報酬整合性を維持したまま、開発・実機確認時だけ報酬受取と達成演出を繰り返し検証できるようにする。

通常画面の「今日の記録をリセット」は、受取済み報酬、bonus XP、クエスト達成記録を取り消さない。これは本番仕様であり変更しない。

## 開発者ページ

`dev-reset.html?dev=1`

`?dev=1` がない場合、リセット操作は無効化される。通常アプリからこのページへの導線は置かない。

## 操作1: 報酬・ミッションだけQA初期化

初期化するもの:

- `bonusXp`
- クエスト達成履歴
- 報酬受取台帳
- 達成演出待ちキュー
- 上記を含む `quests` 状態

保持するもの:

- `days`
- `totalSets`
- `stats`
- ユーザー名
- トレーナー設定
- 効果音設定

アプリへ戻ると既存トレーニング記録からクエストが再評価されるため、達成済み条件を再度報酬受取テストへ使用できる。

## 操作2: ゲーム進行を全初期化

初期化するもの:

- `days`
- `totalSets`
- `bonusXp`
- `stats`
- `quests`
- `lastShownLevel`

保持するもの:

- ユーザー名
- トレーナー設定
- 効果音設定
- その他、進行値として明示していない保存設定

## バックアップ

各リセット直前の `muscleMasterStateV2` を `muscleMasterDevBackupV1` へ1件保存する。

「直前の状態を復元」は明示操作のみで実行し、自動復元は行わない。

## PR #10 最終確認フロー

1. 通常アプリでミッションを達成する。
2. 報酬を受け取り、bonus XPが一度だけ加算されることを確認する。
3. 再読み込みして受取済み状態が維持されることを確認する。
4. 未確認の達成演出が再表示され、確認後にキューから消えることを確認する。
5. `dev-reset.html?dev=1` を開く。
6. 「報酬・ミッションをQA初期化」を実行する。
7. アプリへ戻り、既存記録からミッションが再評価され、報酬受取テストを再実行できることを確認する。
8. 通常の「今日の記録をリセット」では受取済み報酬が取り消されないことを再確認する。

## 非目標

- 通常ユーザーが個別報酬を取り消す機能
- サーバー側の管理者機能
- 複数端末間の同期データ消去
