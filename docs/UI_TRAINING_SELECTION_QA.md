# トレーニング選択画面 QA

対象画面: `#quest`  
基準幅: 390px  
対応幅: 320〜430px

## 見た目

- 画面上部で「トレーニング選択」、曜日、メニュー名、セット進捗が読める
- ユーザー名が20文字でもタイトル、説明、リセット操作が重ならない
- キャラクター画像が種目名、回数・時間、XP、セット操作に重ならない
- 5つのカテゴリが欠けず、狭い幅では横スクロールで選択できる
- 種目名が長い場合もXP表示やセット操作がカード外へ出ない
- 完了済みカードと未完了カードの状態が色だけでなく `COMPLETE` とチェックでも判別できる
- 320px、390px、430pxの各幅で横スクロールが画面全体に発生しない

## 操作

- `すべて / 筋力 / 体幹 / 柔軟 / 持久力` の各フィルターが今日のメニューを絞り込む
- 選択中フィルターの `aria-pressed` が `true` になる
- 該当種目がないカテゴリでは空状態が表示される
- セット番号を押すと完了し、もう一度押すと取り消せる
- 完了・取消後も現在のフィルターが維持される
- 今日の進捗、累計セット、XP、能力値が既存仕様どおり更新される
- 今日のリセットで当日分だけが取り消される

## 保存・PWA

- 再読み込み後にユーザー名、トレーナー名、セット記録が復元される
- 既存の `muscleMasterStateV2` データを消去・再初期化しない
- Service Workerのキャッシュ更新後に新しいHTML、CSS、JavaScriptが配信される

## 今回の対象外

- 専用のトレーニング実行画面
- カウントダウン、インターバル、経過時間タイマー
- フォーム動画またはアニメーション
- キャラクター画像の最終差替え
