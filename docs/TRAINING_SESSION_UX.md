# Training Session UX v1

## 目的

ミッション進捗の起点を「未完了セットのボタンを押した」から「実行画面のガイドを完遂してセットを記録した」へ寄せる。

## v1 の責務

- 未完了の QUICK SET は直接完了にせず、対象種目の実行画面を開く。
- ホームのクイック完了導線も実行画面へ送る。
- 回数種目は開始後、一定ペースの回数ガイドを進める。
- 時間種目は既存カウントダウンを最後まで完走する。
- ガイド完遂前は「このセットを完了」を無効化する。
- ガイド完遂後にセットを記録した時点で、従来どおり training:set-completed を発火し、ミッション評価へ接続する。
- 完了済みセットの取り消しは従来どおり許可する。

## 非目標

v1 は運動そのものをセンサーで検証しない。カメラ、加速度、ウェアラブル、姿勢推定、心拍は後続フェーズとする。

したがって v1 の「完遂」は、アプリ上の実行セッションを最後まで進めたという意味であり、身体動作を機械的に証明するものではない。

## UX フロー

1. 種目を選択
2. 実行画面を開く
3. 開始
4. 回数ガイドまたは時間ガイドを完走
5. 「このセットを完了」が有効化
6. セット記録
7. 次セットへ
8. 条件を満たした場合、ミッションが自動達成
9. ミッション画面で報酬を受け取る

## 今後の拡張

- セット間インターバル
- 回数ペース変更
- トレーナー音声カウント
- 種目別の画像・短尺アニメーション
- フォーム確認用メディア
- カメラ/センサー連携による回数・姿勢推定

この層はミッション・報酬の判定ロジックと分離し、トレーニング実行体験だけを担当する。
